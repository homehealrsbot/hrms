# Agent Studio

لوحة تحكم محلية لوكلاء Claude Code — عرض وتعديل وإنشاء وتعطيل من المتصفح.

**أداة عامة لا ترتبط بأي مشروع.** انسخ `agent-studio.py` حيث شئت وشغّله على
أي مجلد. ملف واحد، بلا أي مكتبة خارجية — مكتبة بايثون القياسية فقط.

## التشغيل

```bash
python3 agent-studio.py                  # المجلد الحالي
python3 agent-studio.py ~/work/my-app    # أي مشروع آخر
python3 agent-studio.py . --port 8800    # منفذ مخصص
python3 agent-studio.py . --no-open      # بلا فتح المتصفح
```

ثم افتح `http://127.0.0.1:7788/`. تقدر تبدّل المشروع من حقل المسار في الأعلى
بلا إعادة تشغيل.

## ماذا تقرأ

| النطاق | المسار |
|---|---|
| المشروع | `<المشروع>/.claude/agents/*.md` |
| المستخدم | `~/.claude/agents/*.md` |

وكيل المستخدم الذي يحمل اسم وكيل مشروع يُعلَّم **محجوب** — المشروع يسبق.

## التصنيف والتشغيل/الإيقاف

الوكلاء مجمّعون تلقائيًا ببادئة اسم الملف (`marketing-`، `engineering-`…)،
بلا أي إعداد — الاصطلاح نفسه يعمل في أي مشروع. كل سطر فيه **مفتاح** يوقفه أو
يشغّله فورًا، ولكل مجموعة زرّا **إيقاف الكل / تشغيل الكل**.

الإيقاف يعيد تسمية الملف إلى `.md.disabled` — لا يُحذف شيء، والإرجاع بنقرة.

### من الطرفية، بلا فتح المتصفح

```bash
python3 agent-studio.py . --list                      # اعرض الكل مصنّفًا
python3 agent-studio.py . --off marketing-tiktok-strategist
python3 agent-studio.py . --on  marketing-tiktok-strategist
python3 agent-studio.py . --group-off marketing       # أوقف مجموعة كاملة
python3 agent-studio.py . --group-on  marketing
```

تقبل `--on` و`--off` أكثر من اسم في الأمر الواحد.

## التبويبات

- **الإعدادات** — الاسم والوصف والأدوات والنموذج واللون، بنماذج لا YAML يدوي
- **المحتوى** — متن الوكيل، أي تعليماته الفعلية
- **الدورة** — سبع خطوات: من الملف على القرص إلى المخرجات، مبنية على بيانات
  الوكيل المفتوح نفسه لا على شرح عام
- **الفحص** — تطابق الاسم مع اسم الملف، طول الوصف، صحة الأدوات، وقصر المتن

## قراءة الشارات

| الشارة | المعنى |
|---|---|
| 🟠 `كل الأدوات + Bash` | بلا حقل `tools` — يملك كل شيء |
| 🟠 `Bash` | يستطيع تشغيل أي أمر: يقرأ أي ملف ويرسله لأي وجهة |
| 🔵 `شبكة فقط` | بلا Bash. منفذه الوحيد طلب `WebFetch`/`WebSearch` |
| 🟢 `مقفل` | لا شبكة ولا تنفيذ أوامر |

عدّاد **بلا Bash** في الترويسة هو المقياس ذو المعنى: `Bash` وحده يفتح كل شيء.

## الأمان

- الخادم يستمع على `127.0.0.1` فقط — لا يُرى من الشبكة
- الكتابة والقراءة مقصورتان على مجلدي الوكلاء؛ أي مسار خارجهما يُرفض
- لا ينفّذ أي أمر ولا يتصل بأي خدمة خارجية
- يُبقي الحقول غير المُدارة في الترويسة كما هي (القوائم المتداخلة مثلًا)،
  فالحفظ بلا تعديل يُخرج الملف مطابقًا بايتًا ببايت
